# dsh-interview：会点评、会讲解的 AI 面试陪练

[![npm](https://img.shields.io/npm/v/dsh-interview)](https://www.npmjs.com/package/dsh-interview)
[![Awesome DSH Plugin](https://awesome-dsh-plugin.com/badge.svg)](https://awesome-dsh-plugin.com)
[![Node.js](https://img.shields.io/badge/Node.js-%3E%3D22.5-339933?logo=node.js&logoColor=white)](./package.json)
[![license](https://img.shields.io/github/license/codingayice/dsh-interview)](./LICENSE)

一个为 DeepSeek Harness Web 打造的 AI 面试练习插件，适合准备后端技术面试、复习八股、模拟面试和刷力扣的开发者。

它不只是随机问你几道题，而是陪你完成一次真正的练习：**出题、作答、评分、点评、讲解、重新作答、继续练习和总结复盘**。练习记录会自动保存，随时都能接着练。

[立即安装](#安装) · [开始练习](#开始第一次练习) · [查看全部功能](#你可以做什么) · [反馈问题](https://github.com/codingayice/dsh-interview/issues)

## 适合谁

- 正在准备 Java、C++、Go 或通用后端技术面试；
- 背了很多答案，却不知道自己能不能在面试中讲清楚；
- 想根据真实简历练习项目追问；
- 正在刷力扣 Hot 100，希望管理题目和完成进度；
- 希望保留每次回答，长期观察自己的提升。

## 为什么值得用

### 不只告诉你答得对不对，还会把知识点讲明白

回答后，你会得到评分和针对性点评。随后插件会详细讲解当前知识点，并整理一份适合面试时直接表达的答案。

### 每次重新作答都算数

点击“重新作答”不会覆盖旧答案。每次回答、评分和点评都会独立保存，你可以看到自己是怎么一步步答得更好的。

### 一次只问一道题

没有一屏十几个问题，也没有冗长的答题要求。每次只出现一道简洁明确的题目，回答完再进入下一题。

### 想练什么，就练什么

| 模式 | 适合场景 |
| --- | --- |
| 背八股 | 集中复习 Java、JVM、并发、MySQL、Redis 等知识点 |
| 模拟面试 | 根据简历模拟真实面试，配置面试官风格、难度和手撕代码 |
| 场景题 | 练习故障排查、系统设计和项目决策类问题 |
| 刷力扣 | 从力扣 Hot 100 随机抽题，按指定语言查看讲解和代码 |

### 聊天练习，工作台管理

你可以直接在对话中开始练习，也可以打开可视化工作台完成配置、切换练习、查看历史、编辑、删除和导出。简单管理操作直接在本地完成，不需要每次都让 AI 处理。

### 练习记录保存在本地

题目、回答、评分、点评、讲解和简历默认保存在本机，无需额外安装数据库或部署其他服务。

## 你可以做什么

- 创建背八股、模拟面试、场景题和力扣练习；
- 根据主题、简历和难度生成题目；
- 回答问题，获得评分、点评和详细讲解；
- 不作答，直接查看答案和知识点讲解；
- 重新回答同一道题，并保留每次作答记录；
- 自动进入下一题，或随时结束普通练习；
- 结束后查看本次练习总结；
- 在新会话中切换到旧练习并继续；
- 通过时间轴查看题目、作答记录和答案；
- 搜索、筛选、修改、删除和导出练习；
- 查看力扣 Hot 100 题单和完成进度；
- 查看长期练习表现和薄弱主题。

## 安装

需要 DeepSeek Harness Web，以及 Node.js 22.5 或更高版本。

```powershell
dsh plugin --profile web add dsh-interview
```

安装完成后重启 `dsh web`。

更新插件：

```powershell
dsh plugin --profile web update dsh-interview
```

## 开始第一次练习

打开页面右下角的“练习工作台”，点击“新建练习”，选择模式并填写配置。

你也可以直接在聊天中说：

```text
开始 JVM 八股练习
```

```text
开始 Redis 高可用场景题练习
```

```text
使用 Java 开始刷力扣
```

## 一次练习是怎样进行的

### 1. 回答当前题目

题目会以卡片形式显示。直接在聊天输入框回答后，你会依次得到：

1. 0～10 分评分；
2. 针对当前回答的点评；
3. 知识点的详细讲解；
4. 一份可以直接用于面试表达的精炼答案。

### 2. 选择下一步

- **重新作答**：保留旧记录，再新增一次回答；
- **下一题**：自动生成下一道简洁题目；
- **结束练习**：结束本次练习并生成总结；
- **看答案**：不提交回答，直接进入讲解。

### 3. 随时继续

练到一半关闭页面也没关系。回到原会话后说“继续练习”，插件会从当前进度恢复。

如果想在新会话继续，先在工作台切换到对应练习。练习会完整转移到新会话，并显示题目时间轴。

## 四种练习模式

### 背八股

填写一个主题，例如 Java 并发、JVM 垃圾回收、MySQL 索引、Redis 高可用或 Spring 事务。适合系统复习，也适合面试前查漏补缺。

### 模拟面试

提供简历，并选择面试官风格、是否手撕代码以及初级、中级或高级难度。题目会结合简历经历展开，适合练习项目介绍和技术追问。

### 场景题

填写想练习的主题，例如“线上接口突然变慢”或“设计秒杀系统”。插件会围绕真实工程场景逐题提问。

### 刷力扣

选择 C++、Java、Python、C 或 Go 后，插件会从[力扣 Hot 100](https://leetcode.cn/studyplan/top-100-liked/)中随机抽题，优先抽取还未完成的题目。

## 练习工作台

“练习工作台”用于管理全部练习。

### 进行中

显示还没有结束的普通练习和当前力扣题。你可以新建、切换、查看详情、编辑配置、删除或导出练习。

### 练习档案

只显示已经结束的练习。你可以查看完整题目、历次回答、评分、点评、讲解和总结，也可以重新打开继续练习。

### 热题 100

按题型展示完整的力扣 Hot 100 题单，包括题号、难度、原题地址和完成状态。

## 题目时间轴

只有当前会话明确新建或切换到一条练习后，时间轴才会出现。点击节点可以查看题目、每次回答及点评，以及详细讲解和参考答案。

一条练习同一时间只绑定一个会话。在新会话切换这条练习后，旧会话会自动解除绑定，避免两个会话同时推进同一练习。

## 数据与隐私

练习数据库默认保存在：

```text
%USERPROFILE%\.dsh\profiles\web\data\dsh-interview\interview.sqlite
```

Markdown 默认导出到：

```text
%USERPROFILE%\.dsh\profiles\web\data\dsh-interview\exports
```

请不要把包含真实简历或回答的数据库和导出文件提交到公开仓库。

## 常见问题

### 重新作答会覆盖以前的回答吗？

不会。每次回答以及对应的评分和点评都会单独保存。

### “继续练习”和“下一题”有什么区别？

“继续练习”会恢复尚未完成的当前步骤；“下一题”只在当前题完成后生成新题。

### 为什么练习档案是空的？

练习档案只显示已经结束的练习。尚未结束的练习显示在“进行中”。

### 哪些操作会使用 AI？

出题、评价、讲解和普通练习总结需要 AI。搜索、筛选、切换、编辑、删除、导出和修改力扣完成状态由工作台直接完成。
