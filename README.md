# dsh-interview

[![npm](https://img.shields.io/npm/v/dsh-interview)](https://www.npmjs.com/package/dsh-interview)
[![Node.js](https://img.shields.io/badge/Node.js-%3E%3D22.5-339933?logo=node.js&logoColor=white)](./package.json)
[![license](https://img.shields.io/github/license/codingayice/dsh-interview)](./LICENSE)

面向 DeepSeek Harness Web 的本地优先 AI 面试训练插件。

它不只是让模型在聊天里随机提问，而是把练习配置、题目、历次回答、评分、点评讲解和练习总结组织成一套可恢复、可查询、可导出的训练系统。你既可以直接用自然语言练习，也可以通过可视化工作台管理全部数据。

## 为什么使用 dsh-interview

- **完整训练闭环**：出题、作答、评分、详细讲解、直接背、重答、下一题和练习总结全部串联。
- **四种练习模式**：覆盖背八股、模拟面试、场景题和力扣 Hot 100。
- **一题一问**：每轮只出现一道简洁问题，不把多个子问题和提示清单塞进题目。
- **保留每次进步**：重新作答会新增记录，不会覆盖以前的回答、评分和点评。
- **自然语言 + 可视化 UI**：聊天负责训练，工作台负责配置、查询、切换、编辑、删除和导出。
- **本地优先**：简历、回答和练习档案默认保存在本机 SQLite，不需要部署数据库服务。
- **可恢复工作流**：说“继续练习”时，插件根据持久化状态恢复当前题、待评价回答、待生成讲解或待总结阶段。
- **控制模型费用**：列表查询、搜索筛选、练习切换、CRUD、导出和力扣完成状态等管理操作可直接在本地 UI 完成。

## 功能一览

| 能力 | 说明 |
| --- | --- |
| 新建练习 | 使用可视化表单或自然语言创建，所有必要配置都必须由用户明确选择 |
| 面试出题 | 一次只生成一道简洁题目，并在聊天中显示题目卡片 |
| 回答与评价 | 保存原始回答，生成 0–10 分评分、文字点评和可选维度评分 |
| 点评讲解 | 提供知识点的详细讲解，并在结尾给出可直接背诵的精炼答案 |
| 直接看答案 | 不伪造用户回答和评分，直接进入详细讲解 |
| 多次作答 | 每次重答都保存为独立记录，对应自己的评分和点评 |
| 练习总结 | 结束普通练习时，根据全部题目和作答历史生成亮点与改进建议 |
| 题目时间轴 | 当前会话选择练习后显示；可查看题目、历次作答与答案 |
| 练习工作台 | 管理进行中练习、已结束档案和力扣 Hot 100 题单 |
| CRUD | 支持练习和普通面试题目的查询、修改、删除，以及练习切换和重新打开 |
| Markdown 导出 | 将题目、回答、评价、讲解和总结导出为本地文档 |
| 能力复盘 | 汇总平均分、主题掌握情况和薄弱主题 |

## 工程亮点

- **显式领域状态机**：出题、等待回答、等待评价、生成讲解、等待下一题和生成总结都有唯一合法转换，避免模型凭文本猜测流程。
- **原子 Agent 工具**：每个工具只执行一个业务动作，参数通过 JSON Schema 声明，缺少题目、配置或回答时不会写入半成品数据。
- **统一应用层**：自然语言工具和 React UI 共用 `InterviewCoordinator`、应用用例和领域模型，不会出现两套业务规则逐渐分叉。
- **事实与生成任务分离**：领域事件记录已经发生的事实，`agentTasks` 只表示确实需要模型生成内容或追加正式会话卡片的任务。
- **事务化本地存储**：SQLite Repository 使用事务和外键保存完整练习聚合，并在数据库层约束一条练习只能绑定一个会话。
- **结构化 UI 协议**：Client 根据稳定资源引用读取权威数据，不依赖解析 Assistant 的自然语言文本来决定显示哪张卡片。

## 四种练习模式

插件不会猜测配置，也不会自行使用默认值。模式不明确时只询问模式；模式明确后只收集该模式缺少的字段。

| 模式 | 必填配置 | 适合场景 |
| --- | --- | --- |
| 背八股 | 主题 | 集中复习 JVM、并发、MySQL、Redis 等知识点 |
| 模拟面试 | 简历、面试官风格、是否手撕代码、难度 | 根据个人经历进行完整技术面试演练 |
| 场景题 | 主题 | 练习系统设计、故障排查和工程决策 |
| 刷力扣 | 编程语言 | 从力扣 Hot 100 随机抽题并获取指定语言讲解 |

模拟面试难度可选择初级、中级或高级。刷力扣支持 C++、Java、Python、C 和 Go。

## 典型练习流程

```text
选择模式并完成配置
        ↓
一次生成或抽取一道题
        ↓
回答问题 ─────────────→ 直接看答案
    ↓                         ↓
保存回答并评分            生成详细讲解
    ↓                         ↓
点评讲解 + 直接背 ←──────────┘
        ↓
重新作答 / 下一题 / 结束练习
```

### 回答问题

直接在正常聊天输入框作答即可。回答保存后，Agent 会继续完成：

1. 保存本次原始回答；
2. 生成 0–10 分评分和文字点评；
3. 详细讲解当前知识点；
4. 给出可直接背诵的精炼答案。

如果点击“重新作答”，先前记录会完整保留，新回答会创建新的作答记录。

### 直接看答案

题目卡片提供“看答案”或“讲解”入口。直接看答案不会创建虚假的用户回答、评分或评价，只生成当前题目的详细讲解。

### 继续练习

“继续”不是“下一题”的别名。插件会读取当前权威状态：

- 正在等待回答：恢复当前题；
- 回答尚未评价：继续完成评价；
- 点评讲解尚未生成：继续生成讲解；
- 已完成当前题：进入下一题；
- 正在结束练习：继续生成总结；
- 当前会话没有选择练习：提示先从工作台选择。

## 力扣 Hot 100

插件内置[力扣 Hot 100](https://leetcode.cn/studyplan/top-100-liked/)题单快照，保存 100 道题的官方地址、题型和难度。

力扣模式具有独立的练习模型：

- **一道题就是一条练习**，练习内容直接显示题目名称；
- 题目由插件从固定题库随机选择，不允许模型自行编题；
- 优先从尚未完成的题目中抽取；
- 点击“随机下一题”后，上一条练习自动归档，新题创建为新的练习；
- 按钮会立即变为“已出下一题”，前端与应用层共同阻止快速双击导致重复抽题；
- 旧题卡保持不变，新题卡追加在会话最新位置；
- 可以打开力扣原题，并独立标记完成或未完成；
- 题库按题型分组展示，并显示全局完成进度；
- 讲解只输出配置语言的一份完整可提交代码，不会混入其他语言。

力扣讲解包括题意与约束、方案推导、算法步骤、正确性、边界情况、时间复杂度、空间复杂度和答案代码。力扣题卡不提供“结束练习”按钮；抽取下一题时自动归档当前练习，停留在当前题时则保留为进行中。

## 可视化练习工作台

页面右下角的“练习工作台”提供三个入口：

### 进行中

- 新建练习；
- 搜索并按模式筛选；
- 切换到某条未结束练习；
- 查看完整题目与作答详情；
- 编辑练习配置；
- 修改或删除普通面试题目；
- 删除或导出练习。

### 练习档案

- 只展示已经结束的练习；
- 查看题目、历次回答、评分、点评、讲解和总结；
- 将已结束练习重新打开；
- 删除或导出历史练习。

### 热题 100

- 按官方题型查看 100 道题；
- 查看题号、难度、原题地址和完成状态；
- 在本地标记完成或未完成；
- 查看整体及各题型完成进度。

工作台的配置项和筛选器使用统一的自定义下拉组件，支持键盘选择、点击外部关闭和明确的选中状态。

## 题目时间轴与会话绑定

新会话默认不会自动加载任何练习，也不会显示题目时间轴。只有新建、切换或重新打开练习后，当前会话才会绑定该练习。

- 一条练习同时只能绑定一个会话；
- 在新会话切换同一练习时，练习进度会完整转移；
- 旧会话立即解除绑定；
- 时间轴只展示当前会话明确选择的练习；
- 点击节点默认打开“题目”标签，也可以查看“作答记录”和“答案”；
- 每条作答记录包含回答、评分和点评。

## 安装

### 环境要求

- DeepSeek Harness Web
- Node.js 22.5 或更高版本

插件使用 Node.js 内置 SQLite，无需安装 MySQL、PostgreSQL 等外部数据库。

### 安装插件

```powershell
dsh plugin --profile web add dsh-interview
```

安装完成后重启 `dsh web`。

更新插件：

```powershell
dsh plugin --profile web update dsh-interview
```

## 哪些操作会使用模型

dsh-interview 将“管理数据”和“生成内容”分开处理。

通常在本地完成的操作：

- 查看、搜索和筛选练习；
- 切换练习和打开历史题；
- 修改、删除和导出练习；
- 修改或删除普通面试题目；
- 查看 Hot 100 和修改完成状态；
- 从固定题库随机选择力扣题目。

需要 Agent 参与的操作：

- 生成普通面试题；
- 评价用户回答；
- 生成点评讲解或力扣算法讲解；
- 生成普通练习总结；
- 将新抽取的力扣题卡追加到正式会话位置。

通过工作台执行 CRUD 可以避免为了简单的数据管理反复让模型理解自然语言意图。

## 数据与隐私

默认数据库位置：

```text
%USERPROFILE%\.dsh\profiles\web\data\dsh-interview\interview.sqlite
```

默认导出目录：

```text
%USERPROFILE%\.dsh\profiles\web\data\dsh-interview\exports
```

默认保存在本地的数据包括：

- 练习配置和简历；
- 题目；
- 每次用户回答；
- 评分与点评；
- 详细讲解与直接背；
- 练习总结；
- 力扣完成状态；
- 会话与练习绑定关系。

请勿将本地 SQLite、导出文件、真实简历、回答或会话日志提交到公开仓库。

## 架构

Agent 工具和 React UI 不会各自维护一套业务逻辑。两种入口统一经过协调器、应用用例和领域状态机，再访问本地基础设施。

```text
DSH Agent ─┐
           ├─ adapters ─→ coordinator ─→ application ─→ domain
React UI ──┘                                      │
                                                 └─ ports ← infrastructure
```

```text
src/
├── domain/          练习聚合、校验规则和工作流状态机
├── application/     用例、协调器、DTO、交互结果和端口
├── infrastructure/  SQLite Repository、Markdown 导出和系统能力
├── adapters/        DSH 原子工具、HTTP API 和 Agent 事件桥接
├── client/          React 功能模块、共享组件和样式系统
└── protocol/        Agent 与 Client 共享的协议常量
```
